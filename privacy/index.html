Privacy

This page explains how Exile handles data while providing moderation features in Discord.

What Exile processes

Exile automatically processes Discord message content and related metadata in servers where it operates to detect spam. This can include user, server, channel, and message identifiers; usernames and channel names; timestamps; attachments and stickers; member and permission information; and moderation actions or errors.

How data is used

Exile uses this data to identify and respond to spam, remove affected messages, take configured moderation actions, create incident receipts, and let authorized moderators review and resolve incidents.

Exile does not sell Discord data, use it for advertising, or use message content to train artificial intelligence models.

Storage

Exile does not write ordinary Discord message content to a separate persistent database. Message data may remain temporarily in runtime memory and service caches while Exile operates.

Hosting systems may retain limited operational logs, such as identifiers, channel names, action results, and error information, for operation and troubleshooting. Exile also retains the server configuration needed to operate, which can include the server name and server, channel, and role identifiers.

Receipts in Discord

When Exile responds to an incident, a receipt is posted inside Discord. It may contain account identifiers, message evidence, copied images, channel names, and the outcome of moderation actions.

Receipts are ordinary Discord messages and remain in the server until someone with appropriate permissions deletes them. Exile does not keep a separate receipt database.

Sharing

Data is sent to Discord to perform moderation actions and post receipts. Service providers used to host and operate Exile may process limited data on the operator's behalf. Exile does not disclose Discord data to advertisers or data brokers.
